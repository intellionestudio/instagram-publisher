Carousel Workshop 개인정보처리방침

운영자·개인정보 보호 담당: Easy AI Lab
문의·열람·정정·삭제·처리정지 요청: easyailab@naver.com
시행일: 2026년 10월 24일

Carousel Workshop은 Easy AI Lab의 Instagram·Threads 계정 easyai_lab을 위한 개인 운영 도구입니다. Instagram 댓글·DM은 기본적으로 응답안만 기록합니다. 운영자가 자동 전송을 명시적으로 켜면 이후 수신되는 일치 댓글에 공개 답글을, 일치 DM에 비공개 답장을 미리 설정한 고정 문구로 보냅니다. 규칙을 바꾸거나 자동 전송을 끄면 새 자동 발송을 중지합니다. 별도의 건별 수동 승인 전송도 지원합니다.

1. 처리 목적과 범위

운영자가 제작한 카드뉴스의 게시·예약·상태 확인, 연결 계정 인증, Instagram 댓글·DM 수신 검증, 키워드 규칙 시험 및 오류 확인을 위해 정보를 처리합니다. 일반 이용자의 회원가입이나 다른 운영자의 계정 연결은 제공하지 않습니다. 서비스 운영에 필요한 범위에서만 처리하고 광고 판매나 별도의 이용자 프로파일링에 사용하지 않습니다.

2. 처리 항목과 수집 경로

구분정보와 사용 방식
계정·인증Meta가 제공하는 연결 계정 ID·사용자 이름, 운영자가 발급한 액세스 토큰, 앱 시크릿 및 검증 토큰. 인증·게시·Webhook 보안에 사용합니다.
게시 자료운영자가 입력한 이미지, 캡션, 해시태그, 대체 텍스트, 예약 시각, 게시 상태·식별자.
수신 이벤트Meta Webhook으로 전달된 댓글·DM 텍스트와 계정·발신자·수신자·이벤트 식별 정보를 메모리에서 처리하여 대상 계정, 본인 메시지, 중복 이벤트를 판별합니다.
클라우드 수신 기록Cloudflare Workers로 상시 수신할 때 서명 검증을 통과한 댓글·DM의 문장, 계정·이벤트·원본 댓글 또는 DM 발신자 식별자, 수신 시각과 본인 메시지 여부를 Cloudflare D1에 저장합니다. 일치 규칙·응답안·전송 상태·플랫폼 답변 ID도 기록합니다. 원본 Webhook 전체는 저장하지 않으며, 인증된 운영자 Workshop만 비공개 조회 토큰으로 읽을 수 있습니다. 자동 전송을 켠 경우 Worker가 Meta를 통해 해당 답변을 보냅니다.
로컬 응답 기록댓글·DM 문장 또는 수동 예문, 응답안, 일치 규칙, 처리 시각·종류·상태를 저장합니다. 실제 수신 중 규칙이 일치한 기록은 수동 승인 전송을 위해 원본 댓글 ID 또는 DM 발신자 ID, 계정 ID, 메시지 시각을 비공개 대상 파일에 보관합니다. 원본 Webhook 전체는 저장하지 않습니다. 중복 확인에는 이벤트 ID의 해시를 사용합니다. 승인한 답변·시도 시각·전송 상태·플랫폼 답변 ID도 비공개로 기록합니다.

본문에 이용자가 적은 이름·연락처 등은 문장에 포함된 상태로 저장될 수 있습니다. 민감한 정보나 불필요한 개인정보를 댓글·DM에 보내지 마세요. 현재 응답안은 고정 문구 규칙으로 작성하며 댓글·DM을 외부 생성형 AI에 전송하지 않습니다. 플랫폼의 계정 접근 승인은 모든 개인정보 처리에 대한 포괄적인 동의로 간주하지 않습니다.

3. 보관기간과 파기

  • Cloudflare D1의 댓글·DM 수신 기록은 7일 경과 후 삭제합니다. 운영자 Mac으로 가져온 댓글·DM 문장, 응답안, 전송 대상 식별자 및 수동 시험 기록은 최대 7일 또는 최근 50개 중 먼저 도달하는 범위로 보관합니다. 이벤트 ID 해시는 최대 7일·최근 1,000개로 제한합니다. 중복 전송 차단용 전송 시도 기록(승인 답변·상태·플랫폼 ID 포함)은 최근 50개 제한과 별도로 최대 7일 보관합니다.
  • 프로그램 실행 중 약 1분마다, 기록 조회 및 프로그램 재시작 시 만료 기록을 파일에서 제거합니다. 컴퓨터가 꺼져 있거나 프로그램이 중지된 동안에는 삭제 작업을 실행할 수 없어 다음 실행 시 정리합니다. 파일 제거는 저장 매체의 물리적 완전 소거를 보장하지 않습니다.
  • 규칙·프로젝트·연결 인증 정보는 운영자가 사용하는 동안 보관하고, 불필요해지거나 연결 종료·삭제 요청을 처리할 때 삭제·폐기합니다. 액세스 토큰은 공개 파일에 넣지 않고 GitHub Actions Secrets, Cloudflare Secret 또는 로컬 비공개 파일로 관리합니다.
  • 공개 게시 자료와 게시 상태는 별도입니다. 현재 전용 GitHub 저장소에 게시용 자료·메타데이터가 저장되고 GitHub Pages 이미지가 공개됩니다. 수신 기록의 7일 정책이 공개 게시물·Git 이력·외부 제공자 로그에 자동 적용되는 것은 아닙니다. 공개 자료 삭제 요청 시 원본 게시물, 저장소 이력, 캐시 등의 범위를 구분해 확인합니다.

4. 외부 서비스 이용

필요한 인증·게시 및 이벤트 전달에는 Meta(Instagram·Threads)를, 공개 이미지 호스팅·게시 실행·Secret 저장에는 GitHub를 사용합니다. 실제 댓글·DM 수신은 Cloudflare Workers에서 처리하고 D1에 임시 보관한 뒤 인증된 운영자 Mac의 Workshop으로 가져옵니다. 기존 임시 터널 수신 방식도 시험용으로 남아 있습니다. Mac의 Workshop 편집 화면·규칙 API·프로젝트 파일은 공개하지 않습니다. 댓글·DM 수신 기록을 GitHub 게시 대기열에 업로드하지 않습니다.

해당 제공자들은 해외에 본사를 두거나 글로벌 인프라를 운영하므로 서비스 과정에서 국외 처리가 수반될 수 있습니다. 자체 서버의 처리 국가를 하나로 고정하거나 외부 제공자 로그의 보관기간을 이 방침의 7일로 단정하지 않습니다. 적용되는 계약·법령상 별도 고지·동의 등 절차가 필요한 경우 이를 확인하고 해당 처리를 진행합니다. 각 제공자의 정보 처리 사항은 아래 공식 정책에서도 확인할 수 있습니다.

  • Meta 개인정보처리방침
  • GitHub 개인정보처리방침

5. 이용자의 권리와 삭제 요청

easyailab@naver.com으로 열람·정정·삭제·처리정지를 요청할 수 있습니다. 제목에 “Carousel Workshop 개인정보 요청”을 적고, 관련 계정과 대략적인 댓글·DM 시각 등 확인에 필요한 최소 정보를 알려주세요. 비밀번호·API 토큰·주민등록번호·신분증을 보내지 마세요. 대상 식별자가 없는 과거 시험 기록은 대상 기록을 찾기 위한 추가 확인이 필요할 수 있습니다.

운영자는 요청을 확인하고 적용 법령에 따라 지체 없이 처리하거나 제한 사유를 안내합니다. 로컬 기록 삭제와 Instagram·Threads 원본 댓글·메시지·게시물 삭제는 다릅니다. 원본은 해당 서비스의 삭제 기능 또는 별도 절차로 처리합니다. 구체적인 절차는 데이터 삭제 안내를 참고하세요.

6. 보호 조치

Meta 원문 요청의 HMAC-SHA256 서명 검증, 지정 계정 이벤트 제한, 본인 메시지·중복 이벤트 제외, Cloudflare Secret과 비공개 D1·관리자 토큰, 비공개 로컬 파일 접근 권한, 수신 서버와 편집 서버 분리, 토큰·시크릿·원문 요청의 일반 수신 로그 기록 금지 조치를 적용합니다. 운영체제 백업과 서비스 제공자 로그의 존재까지 부인하는 것은 아닙니다. 자동 전송은 기본 차단되고 운영자가 별도로 켜야 하며 규칙 변경 시 중지됩니다. 전송 시도는 먼저 기록하고 결과가 불확실하면 자동 재시도하지 않습니다. 수동 전송은 15분 허용 만료와 건별 승인을 적용합니다. 전송한 답변은 Meta와 해당 수신자에게 전달되고 댓글 답글은 공개됩니다.
